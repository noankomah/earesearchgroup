# First repository setup

This is the standalone Django project, copied from the existing local work.

- Create a new empty GitHub repository, for example `earg-django`.
- Leave the GitHub README, .gitignore and license initializers unchecked; this folder already contains its project files.
- No remote, commit, push or deployment is created by this preparation.
- The files are staged locally for review and the first commit. Share the new repository URL when you are ready to connect it.

The original development database, admin account and uploads stay in the old working folder. They are not included in this source copy. For now, continue using the existing local preview there. A fresh checkout can be started using README.md; content/data transfer will be handled separately.

Do not commit .env files, database exports, local databases, media uploads, virtual environments or collected static files. The included .env.example contains placeholders only.
